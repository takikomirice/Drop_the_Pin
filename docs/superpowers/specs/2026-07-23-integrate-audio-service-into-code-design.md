# AudioService.js の Code.js 統合設計

## 目的

Google Apps Script のサーバーコードを `Code.js` の1ファイルへ集約する。音声保存、Driveメディア構造、音声読込の既存動作、公開関数、レスポンス、永続化形式は変更しない。

## 採用方式

現在のローカルテストが評価する `Code.js`、`AudioService.js` の順序を保ち、`AudioService.js` の内容を `Code.js` の末尾へそのまま移す。その後 `AudioService.js` を削除する。統合と同時の関数再配置、命名変更、リファクタリングは行わない。

代替案として、音声関数を関連する `Code.js` の各節へ分散する方法と、デプロイ時だけ生成物を連結する方法がある。前者は差分と回帰リスクが大きく、後者はソース統合という目的を満たさずビルド工程も増やすため採用しない。

## テストとツール

- ルート直下の Apps Script JavaScript が `Code.js` だけであることを構造テストで固定する。
- 音声・Driveテストハーネスは `Code.js` だけを読み込む。
- `package.json` の構文検査から削除済みファイルを外す。
- 対象テストで RED/GREEN を確認後、全Nodeテスト、JavaScript構文検査、vendor同期検査、ブラウザテスト、差分検査を実行する。

## 互換性とドキュメント

コードの評価順序と内容を維持するため、外部API、シート列、Drive構造、エラーコードへの影響はない。利用方法や設定も変わらないためREADMEの説明更新は不要とする。
