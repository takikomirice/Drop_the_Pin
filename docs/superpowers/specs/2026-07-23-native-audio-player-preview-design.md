# 編集・プレビュー・共有ビューのネイティブ音声プレーヤー設計

## 状態

2026-07-23、利用者承認済み。音声編集で生成したMP3の確認再生と同じブラウザ標準の`<audio controls>`を、保存済み音声ピンの編集モード、編集URL内のプレビューモード、共有URLで使用する。すべての音声プレーヤーで、対応ブラウザの標準メニューにあるダウンロード項目だけを非表示にする。

## 目的

- 編集URL内のプレビューモードで、音声付きピンの詳細にプレーヤーが表示されない回帰を修正する。
- 編集モード、プレビューモード、共有URLの再生UIを、音声編集結果に使っているネイティブプレーヤーへ統一する。
- 既存の認証、共有投影認可、遅延取得、LRUキャッシュ、Object URL解放を維持する。
- ピン、音声、Drive、Spreadsheetの公開API、レスポンス形状、永続化形式は変更しない。

## 原因

`index.html`の`openPinDetail()`は、`canEdit() && pin.hasAudio`のときだけ編集用音声プレーヤーを開く。`canEdit()`は変更操作の可否を表すため、編集URL内でもプレビューモードでは意図的に`false`になる。その結果、有効な編集トークンを保持していて音声を安全に取得できる状態でも、プレーヤーが閉じられる。

音声の閲覧可否とピンの変更可否を同じ条件で判定していることが原因であり、サーバーの`getPinAudioData`認証や音声データ自体の欠落ではない。

## 検討案と採用方針

### A. ネイティブ`audio controls`を共通利用する（採用）

音声編集結果の`<audio controls preload="metadata">`と同じ操作面を、保存済み音声ピンにも使用する。再生、一時停止、シーク、音量、追加メニューはブラウザに委ねる。既存コントローラーは認証済みデータ取得、Blob変換、キャッシュ、画面遷移時の停止と解放を担当する。

ネイティブUIのためブラウザごとに外観や追加メニューの内容は異なるが、音声編集結果との操作モデルを一致させ、独自のメディア操作実装を増やさずに済む。

### B. 添付UIを独自コントロールで再現する（不採用）

外観は固定できるが、シーク、音量、キーボード操作、スクリーンリーダー対応、ブラウザのメディア状態同期を独自実装する必要がある。音声編集結果のプレーヤーとも実装が分かれる。

### C. 現在の再生／停止ボタンを装飾する（不採用）

変更量は小さいが、利用者が指定した音声編集結果のプレーヤーと操作が一致せず、シーク、音量、追加メニューも提供できない。

## 表示とアクセス条件

`index.html`では、ピンに`hasAudio === true`があり、現在のページが有効な編集トークンを保持するときに音声を開く。変更操作用の`canEdit()`は音声閲覧の判定に使わない。この分離により、編集モードと同じ編集セッション内のプレビューモードで`getPinAudioData`を利用できる。通常URLには編集トークンがないため、従来どおり編集用APIを呼ばない。

`shared.html`では、従来どおり`hasAudio === true`の共有対象ピンを開いたときだけ`getSharedPinAudioData`を呼ぶ。共有トークンとピンIDだけを送り、編集トークンを共有ページへ持ち込まない。

両ページとも一覧表示、地図描画、初期ロードでは音声本体を取得しない。ピン詳細を開いた後にだけ取得する現在の遅延取得境界を維持する。

## 共通プレーヤーUI

`index.html`と`shared.html`の固定マーカー間にある共通プレーヤーブロックは、引き続きバイト単位で同一にする。

- プレーヤー本体は`<audio id="pin-audio-runtime" controls controlsList="nodownload" preload="metadata">`とする。
- 音声がない状態と詳細を閉じた状態では、コンテナとプレーヤーを非表示にする。
- 読み込み中はコンテナと「音声を準備中…」を表示し、まだ再生できないネイティブプレーヤーは非表示にする。
- 取得成功後は状態文言を消してネイティブプレーヤーを表示する。
- 取得失敗時は「音声を再生できませんでした」と「再試行」を表示し、プレーヤーを非表示にする。
- プレーヤーはコンテナ幅を超えないよう`width: 100%`と`max-width: 100%`を設定し、狭い画面で横スクロールを発生させない。
- `aria-label`を付け、再生操作そのもののキーボードと支援技術対応はブラウザ標準コントロールへ委ねる。

音声編集結果のプレーヤーにも`controlsList="nodownload"`を追加し、対応ブラウザでは縦三点メニュー内のダウンロード項目だけを非表示にする。再生速度など、それ以外のブラウザ標準操作は削らない。`controlsList`の解釈やメニュー構成はブラウザに依存するため、未対応ブラウザではダウンロード項目が残る可能性がある。音声は再生のためブラウザへ既に配信されるため、UIでダウンロードを隠しても取得を技術的に防止できるものではない。

## コントローラーとデータフロー

既存の`AudioPinPlayer`は次の責務を維持する。

1. 詳細を開いたピンIDを正規化する。
2. 編集ページでは`getPinAudioData`、共有ページでは`getSharedPinAudioData`を呼ぶ。
3. MP3 MIME、バイト数、Base64形式と復号後サイズを検証する。
4. MP3 BlobからObject URLを生成し、ネイティブ`audio`の`src`へ設定する。
5. 最大3件かつ12MBのLRUキャッシュを維持する。
6. ピン切替、詳細クローズ、音声差し替え・削除、`pagehide`で停止、リセット、失効、Object URL解放を行う。
7. 遅延応答が別ピンや閉じた詳細へ反映されない世代管理を維持する。

独自の再生／停止ボタンと、それを駆動する`toggle()`公開操作はUIから外す。再生と一時停止はネイティブ`audio`が直接扱う。コントローラーはクローズやピン切替時に`pause()`と`currentTime = 0`を実行するため、画面外で再生を継続しない。

## エラー処理と安全境界

- MP3レスポンスが不正、範囲外、復号不能の場合はObject URLを作らず、再試行可能な安全なエラー表示にする。
- エラー表示へDrive ID、音声ID、Base64、編集トークン、共有トークン、内部エラー詳細を出さない。
- 編集用取得は引き続き`getPinAudioData`の編集トークン検証を通す。
- 共有用取得は引き続き共有リンクの有効性、対象ピン投影、`hasAudio`をサーバーで再検証する。
- 読み込み中に詳細を閉じる、別ピンへ切り替える、再試行する場合は、古い応答を表示しない。
- ネイティブプレーヤーの見た目と一部の操作はChrome、Edge、Safariなどで異なることを許容する。

## テスト方針

テスト駆動で、実装前に次の失敗する回帰テストを追加または更新する。

- 共通ブロックに`audio[controls][controlsList~="nodownload"]`が1件あり、独自の再生／停止ボタンがない。
- 音声編集結果のプレーヤーにも`controlsList="nodownload"`があり、他の標準操作を抑止するトークンを指定しない。
- `index.html`と`shared.html`の共通ブロックがバイト単位で同一である。
- rendererがhidden、loading、ready、errorをネイティブプレーヤー、状態文言、再試行へ正しく投影する。
- 編集ページの`openPinDetail()`が、`canEdit()`ではなく有効な編集トークンを閲覧条件として音声を開く。
- プレビューモードでも音声付きピンの詳細を開くと編集認証付き取得が1回だけ行われる。
- 通常URLでは編集用音声取得を開始しない。
- 共有URLでは共有トークンだけで取得し、編集トークンを送らない。
- 取得失敗後の再試行、別ピンへの切替、詳細クローズ、LRU失効、`pagehide`解放が維持される。
- 編集、プレビュー、共有の各ブラウザテストでネイティブプレーヤーが表示され、再生操作ができる。
- 375px、768px、1280px幅でプレーヤーと詳細面に横方向のオーバーフローがない。

集中テスト後に`npm run check`と全Playwrightテストを実行する。

## ドキュメントと互換性

READMEの「再生／停止だけを表示し、音量、再生速度、シーク、ダウンロードの操作は表示しない」という説明を更新し、編集・プレビュー・共有URLでブラウザ標準プレーヤーを使うこと、対応ブラウザではダウンロード項目だけを非表示にすること、表示される操作や外観がブラウザによって異なること、配信済み音声の保存を技術的に禁止できないことを記載する。

サーバーAPI、音声レスポンス、共有投影、Drive配置、Spreadsheet列、音声編集・保存処理には変更を加えない。利用者から見える変更は、プレビューモードでの音声表示復旧と、保存済み音声の再生UIがブラウザ標準プレーヤーへ変わることに限定する。
