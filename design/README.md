# UI Design References

## Source of truth

The UI design source of truth is:

- `pencil/Drop the Pin! v1.4.0 UI Redesign.pen`

## Reference screenshots

Files under `references/` are visual comparison materials exported with the UI redesign. They cover the available desktop and mobile UI states. The original export filenames are retained because individual page and color-mode assignments cannot be determined with certainty from every image alone.

## Rules

- The `.pen` file is the primary design source.
- Screenshots are supplementary comparison materials.
- Do not change application behavior, APIs, storage formats, or existing wiring based only on these files.
- Before editing the `.pen` file, pull the latest `v1.4.0` branch.
- Do not edit the same `.pen` file concurrently on multiple computers.
